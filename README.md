# Pokédex do Henrique

Pokédex funcional para celular: 1025 Pokémon com fotos oficiais, grito de cada um, voz que lê a descrição em português, versão brilhante, evoluções, fraquezas, status, "Pegar" Pokémon e o jogo "Quem é esse Pokémon?".

Dados: [PokeAPI](https://pokeapi.co). Uso pessoal/doméstico.

## Como abrir no celular
Publique com GitHub Pages (Settings → Pages → Deploy from branch → `main` / root) e abra o link no celular.
No iPhone: Safari → Compartilhar → "Adicionar à Tela de Início". No Android: Chrome → ⋮ → "Instalar app".
